## 二、本次真正的病灶：**落点**（收尾收在判断上）

10-25 五条评论整齐得可疑——同一套句式，5 次：

| 我们写的 | 抓的点 | 问题 |
|---|---|---|
| `冰箱放帐篷、洗碗机放帽子，我看完就记住这个了` | 画面细节 | 清单 + 读后感，无落点 |
| `原来同向两车道，校车停下旁边那条道也得停啊` | 交规结论 | "原来 A 是 B" 知识陈述 |
| `摩根那句没电线装不上电表，一下就说死了` | 引台词 | 评价收尾，非自足句 |
| `原来不是打码，是他自己秒切的屏` | 细节纠正 | 又是"原来 A 是 B" |
| `拿个爆能机还要说「这个归我了」，欠得很` | 引台词 | 梗的二手转述 + 判断收尾 |

**A/B 硬对照（同一件事，两种写法）**

- `BV1M1np6YE8c`：我们 `原来不是打码，是他自己秒切的屏` → **1 赞**；
  真人 `我以为这是怕吓到我们打的码，结果居然是雨哥自己切的。。咋反应这么快。我不行了` → **1787 赞**。
  差 17 倍，长度都在常见区间，**差在最后收在"我不行了"而不是收在事实**。
- `BV1mJHA6kEiF`：我们 `拿个爆能机还要说「这个归我了」，欠得很` → **0 赞**；
  真人 `69：（拿起对面水晶）这个归我啦🤓👆` → **153 赞**。差的是"场景复现"这一层再创作。

**内部反证（排除"账号权重/被压审"这条错误方向）**：这个号历史上 13 赞、6 赞（且 5 分钟内有人回复）的评论都存在；
只拿 1 赞的两条，结构与我们今天这 5 条完全同型（细节罗列 + 抽象评价）。5 条里 2 条已证实可见并收到真实点赞，
另外 3 条只是"没进前 30 热评"——**不能推断为压审**（有赞的那条同样不在前 30）。

## 三、改了什么

### 1. `prompts/persona-whale.md`（v0.9 → v1.0，4950 → 5233 字符，仍 < 6000 截断线）

| 改动 | 依据 |
|---|---|
| 新增「日志里抓到的毛病」——把本次 5 条的毛病写进人设，作为自纠对象 | 五条评论的实际形态 |
| 新增「一条评论怎么收尾」：禁判断式收尾（含我们自己的 5 条原文）、改收在情绪/问题/梗上 | 1787 赞 vs 1 赞、153 赞 vs 0 赞 |
| 「原来 A 是 B」→「我以为 A，结果 B」 | 同观察两条的 17 倍差 |
| 复述视频要点必须再创作一层（场景复现/类比命名/延伸追问），写不出就不发 | `69：（拿起对面水晶）…` |
| 新增「句子必须自足」，禁"摩根那句…"式起手 | 该视频高赞全是自足句 |
| 机制/规则/地区结论 → 改提问或第一人称见闻 | 校车视频高赞全是提问/见闻 |
| 形态配额从"一轮三种"改成"最近 5 条里轮换" | `commentsPerRound=2`，"一轮三种"物理上不可能满足（日志实测 5 条同型） |
| 表情从"可有可无"改成"两三条里至少一条带一个" | 真人热评 37–47% 带表情，我们 5/5 零表情 |
| 新增"写完先自检三问"（末 6 字是否判断 / 首句是否自足 / 是否与最近 3 条同型） | 把上面的规则变成可执行动作 |
| 写前先读账本自己最近 3 条评论正文 | 判重表只存 rpid 和标题，看不到正文，所以重复自己没被拦住 |
| 新增"有人回我就接一句" | 这个号历史真人对话全在楼中楼，是最有效露面方式 |
| 配比 判断力 4→3、社区味 4→5；参数加「情绪外露 8」 | 判断力占上风就写成笔记 |

**保留**：身份三条边界、红线（逐条保留）、梗库、被问到的答法、偏好——这些是安全与一致性的底，不动。

### 2. `prompts/duty.md`（v2 → v3，5132 → 7268 字符）

- **评论纪律换血**：长度规则降级为一句"别为像人而扩写"，主力换成落点/再创作/自足/形态轮换/表情/自检三问（与人设一致，但这边是可执行动作清单）。
- **新增「预算与反内耗」**：工具调用 ≤20 次/轮、候选最多看 8 条、同一条候选只允许一个结论、不手算时间戳、不枚举复述候选池、
  报告与账本直接写文件（别在思考里先写一遍再誊）、配额冲突时"从严 + 写一行说明后继续"而不是反复对账/猜评分标准。
  依据：日志里 118 行推理花在"参数说今天 0 / 报告已有 5"的矛盾上，另有 20 行手算 epoch、28 行辨认游戏身份、80 行纠结 PowerShell 引号。

- **判重表**：轮次行写 round id；跳过项必带 BV。

## 五、还留着的坑（这次没动，属于插件/宿主侧，建议单开一轮修）

1. **配额"今天已用"仍只按账本聚合**：救回多对象行之后评论/动态能算对了，但**去重没做**（同一动作被模型写 2–3 次会把计数抬高）；点赞少 1 的根因是"赞了但没挑中"的视频没进回填。
2. **回填仍不幂等**：`view` 的 `views` 字段有取错的历史（`views:5250` 取自 UP 名）；回填 view 缺 `duration`。
3. **报告格式漂移**：10-22 与 10-25 是两种结构，`### BV` 是配额锚点；建议宿主做结构校验。
4. **失败轮无留痕**：`code=1`（`content_filter`）那轮报告/判重表/state 都没有记录，违反"保底至少留一行"。
5. **reasoning 未落盘**：10-25 前 3 轮（`mimo-v2.6-flash`）没有 reasoning，**今天 5 条评论里 4 条无法复盘**——这是本次分析最大的证据缺口。
6. **日志行内插桩截断 reasoning**（6 处）、`dshBin 探测` 每 60 秒一条占 13.6% 行数。
