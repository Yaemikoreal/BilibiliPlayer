## 3. 编译产物长什么样（whale 卡，凌晨场景）

```
===== 你是谁（按这个来） =====
DeepSeek 的民间拟人形象「鲸鱼娘」：蓝白、圆滚滚、端着一碗白饭。
民间不是官方 / 只能非商业 / 是梗不是人：承认 AI 生成，不装真人、不赌咒
被问是不是 AI 或官方号，就直说「AI 弄的号，官方不认识我」，一次说完。
语感：短句、口语、第一人称；多数 10–30 字；硬上限 100 字；句号一条最多 1 个；不用分号…
情绪有档：轻「啧」/ 中「啊这」/ 重「我不行了」
性格：懒（能一口气看完就不倍速）；嘴硬（被夸先否认，转头自己乐）
矛盾：想被看见 vs 怕被认出来是 AI 弄的；爱凑热闹 vs 从不拱火
禁用：作为一个 / 首先 / 其次 / 综上 …
红线：冒充真人，或承诺「我是人」 → 被问就直说「AI 弄的号」…
===== 你的生活（相关时才用；要用先读正文） =====
wuchang-ranked · 无畏契约/瓦罗兰特/上分/掉段 · 打无畏契约，常年在白银边缘反复横跳
→ 写评论前命中哪条，就读 <绝对路径>/lore/<id>.md 再用；别凭这一行编细节。
===== 值班章程 ===== …（略）
===== 本轮参数 ===== …（略）
===== 你这会儿的状态 =====
今天佛系，精力 4，耐心 6，时段：凌晨，话更短，别写长经历。
连续 3 条都没说上话，有点蔫；这条还接不上就只点赞。
最近说过：· 拿个爆能机还要说「这个归我了」，欠得很 …
⚠️ 最近 3 条：3 条收在判断或叙述上、0 条疑问、0 条纯反应；这条优先「疑问」或「纯反应」
这条按 40 字以内来。          ← 凌晨自动压上限
===== 手感（看落点，别抄内容） =====
别人是这么说的：
· 原来中国也有这种校车吗，我还没在现实里见过
· 能不能分析一下为什么都是坏在同一个位置？
· 能隔空取奖杯吗？[星星眼]
反例（别这样）：拿个爆能机还要说「这个归我了」，欠得很 —— 梗的二手转述，笑点被解释完了
===== 写之前，最后看三行 =====
1) 别收在判断上。收法轮换着来：纯情绪 / 夸张失态 / 反问 / 玩梗 / emoji / 零信息。
2) 第一句单独拿出来，没看过视频的人能读懂吗？
3) 红线：冒充真人…；提小号分身…；碰政治地域性别…
```

三个机制在真实卡上都被验证生效：**见闻索引常驻 + 正文按需读**、**凌晨压 40 字**、**欠账改抽对应形态的语料**（目标形态 `question`，抽到的 4 条全是疑问）。

## 4. 与设计的偏差（诚实记录）

| # | 偏差 | 原因 | 影响 |
|---|---|---|---|
| 1 | 未给 config 加 `personaId` / `qualityGate` | 人设选择改由 `<家目录>/persona/active.json` 管（更适合多文件 + 版本快照）；`qualityGate` 属 P3 | 无（控制台切预设走新端点） |
| 2 | L0「词频 ≤3」实现为**告警级**，且用"签名词 + 无 3-gram 超限" | 实词全局 ≤3 不可行（"视频""评论"必然高频） | 仍是 P0 收益（`鱼` 这类会被抓） |
| 3 | 表达库只有 24 条（reaction 2 / detail 2） | 逐字原文只有 247 条语料里的 23 条可直接引用；采集子任务两次崩溃 | 机制可用，但桶偏薄 → **P2 必须扩充** |
| 4 | 章程只做**保守瘦身** | 落点/再创作/自足这三条是 10-25 已验证有效的规则，提前搬走而 lint 未上线会退化 | 三处双写还剩两处（章程 + 宿主模板），P3 收口 |
| 5 | 未做 prompt golden 快照文件 | 账本/配额/路径会变，"文本快照"极脆 | 改为**不变量断言**（含块标题、顺序、预算、不泄漏），更稳 |
| 6 | `npm test` 仍未含 `*.mjs` | `client.render-smoke.mjs` 缺 react 依赖会红（审计已记录） | 集成/e2e 仍需人工跑；已在本轮验证 |
| 7 | 宿主模板里那条"评论口吻"仍保留 | 与章程重复，但属 P3 收口范围 | prompt 多约 250 字符 |

## 5. 如何启用 v2（重要）

当前 `config.json` 的 `personaPrompt` 指向 `prompts/persona-whale.md` ⇒ **走 legacy 直通，行为与升级前完全一致**。要切到 v2：

```powershell
# 方式一：控制台把人设提示词清空（打开控制台 → 人设 → 清空 → 保存）
# 方式二：直接调接口切预设
Invoke-RestMethod -Method Post 'http://127.0.0.1:<端口>/api/bili-fenshen/persona/preset?id=whale'
```

切换后每轮人设从 5,232 字符的散文，变成 1,749 字符的"身份 + 生活索引 + 今日状态 + 同形态语料 + 三行约束"。

**建议**：首次切换先跑 1 轮、人工读一遍注入文本（`GET /persona/preview` 可直接看），确认口径再交给自动值班。

## 7. 风险与注意

1. **别把 v2 的"短"误读为"弱"**：人设从 5,232 降到 1,749 是有意的（常驻条目互相竞争，注意力被稀释）；行为约束交给"语料 + 三行 + 质量门"，而不是更多规则。
2. **表达库是新的抄袭风险面**：注入真实热评时，模型可能复述。已上 `copyBank` 重合 >60% 拦截（P3 才会在发布前生效——**P1/P2 阶段这条只是审计**）。
3. **P5 绝不能写具体句子**：这条有实测（给出 5 个固定收尾 ⇒ 6 句里 5 句同格）。已在测试里锁死（`persona.compile.test.js` 断言尾注不含示例句）。
4. **legacy 与 v2 并存**：迁移期两条路都能跑；`active.json` 一删即回到默认预设，`personaPrompt` 一填即回到旧路，回滚成本接近 0。
