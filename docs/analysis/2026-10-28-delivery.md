## 2. 改了什么

### 2.1 实时（对应 ①）

- 新增 `lib/overview.js`（纯函数信封，可单测）、`lib/round.js`（轮次盘点/存在感，纯函数）、`lib/realtime.js`（推送中枢：seq 单调 + 250ms debounce + 800ms 最小间隔 + 失败保留旧值并置 degraded）。
- `lib/api.js` 新增 `GET /api/bili-fenshen/stream`：`hello` / `overview`（文件变更、轮次起止、replyTick、配置保存即推）/ 运行中 1.5s `tick`；`/overview` 改为同一信封（`seq/serverTime/dataUpdatedAt/degraded`）。
- `index.js`：运行中进度取 `live.snapshot()`；`round.lastRound` 由账本按 roundId 聚合；`state.json` 双写修正（`lastRunStartedAt` 与上一轮结果分离）；账号 5 分钟缓存（网络抖动不再把「已登录」翻成「未登录」）；CLI 探测 10 分钟缓存（旧版每 60s 重扫并把日志写肥）；2s 兜底轮询改为**按 mtime 变化才重算**（账本最大 5 MB，不白烧 CPU）。
- `client.js`：`useRealtime()` 单一协调器（SSE 优先、`seq` 守卫、`AbortController` 防竞态、断流降级 2s/10s、focus/visibility 立即刷、页头**数据新鲜度徽标**）；概览首屏新增「今日产出」与「接话」，运行详情运行中展开。

### 2.2 主动接话（对应 ②）

- 章程 `prompts/duty.md` v5：新增 **3.5 接话扫描（每轮硬步骤，0 工具成本）**；「接话纪律」重写为硬步骤 + 三类可接（含**轻互动**）+ 预算说明（扫描不占 ≤20）+ 三层去重；报告契约新增机器行 `接话扫描：…` 与「接话段放最后」；记账契约新增 `reply-scan` 事件。
- `lib/report.js`：新增 `parseProactiveScan()`；`parseCommentAction` 改为**先剥离接话段**（修「接话写在前面会把评论回填错」的地雷）。
- `lib/replies.js`：新增 `proactiveTargetsFromLedger()`（近 14 天 `BV→对方 rpid`，注入 prompt 做去重弹药）。
- `index.js`：`quotaFromLedger` 增记 `replyScans/proactiveSkipped`；轮末 `round-end` 追加 `{replyScans, proactiveReplies, proactiveSkipped, proactiveMissing}`，缺失扫描时记 `note` 告警；`backfillFromReport` 补 `reply-scan` 与 `reply-out(proactive)`；`buildDutyPrompt` 注入三行硬步骤 + 已接话清单 + 正确 rpid/root 姿势。
- `lib/activity.js`：`stageOf` 增 `scanned/proactive`，`repliedBack` 只看非 proactive；`bvid:"-"` 不再生成伪卡片。
- `mcp_server.py`：热评子回复补 `rpid`；`bili_reply` docstring 增「主动接话：rpid=对方一级评论，root 留空」。

### 2.3 视觉与信息架构（对应 ③④）

- **7 页签 → 5 页签**：概览（含运行详情）/ 活动（生命周期·时间线·判重表）/ 日报 / 人设（人设卡·素材库·预览与质量）/ 设置（节奏与配额·内容与禁令·运行环境）。
- **每页页头**：唯一 `h1`（20/28/500）+ 一句话 intro + ≤2 个主操作；删掉全局重复状态行。
- **概览重排**：状态条（运行/自动值班/下一轮/新鲜度）→ 今日产出（数字带 + 它说过的原话）→ 接话 → 运行详情 → 配额（日累计/本轮，6 项 3×2，无孤儿瓦片）→ 存在感 + 人设与健康。
- **设置行式化**：label+说明左、控件右、60px 行，不再每字段一大块；脏标记保存条保留。
- **视觉纠错**：补 `.bf-card-foot` 等幽灵规则、字号吸附到 11/12/13/14/16/18/20、配额「用满」不再标红（只有超配才红）。

### 2.4 顺手修掉的既有缺陷

- `test/persona.growth.test.js` 的**跨午夜时间炸弹**：期望值用 UTC 日期，实现在本地日 ⇒ 00:00–08:00（UTC+8）必挂。改为本地日。
- `test/client.render-smoke.mjs` 的 4 条断言写着旧 fixture 文案（`测试视频标题`/`粗体`/`列表项`），改为真实标记（`<strong>`、报告原文）。
- 新增 `scripts/snapshot-console.mjs`：从安装包 asar 里读**宿主真实 `--dsw-*` CSS**，用真 React SSR 渲染控制台各页，供 Chrome 截图做设计评审/回归（DSH 桌面版 Web GUI 需要带 token 的 URL，headless 进不去）。

## 4. 上手验证（重启 DSH 后）

1. 左侧栏「B站分身」→ **概览**：页头右上角应有「数据 刚刚 · SSE」（或轮询），跑一轮后秒表/工具计数/配额在本轮进行中就动。
2. 断网或插件重载时，徽标变红「数据 Nm 前·正在重连」，而不是静默停在旧值。
3. 一轮跑完：概览「接话」卡出现「上轮 扫描 N → 接 M / 不接（理由）」；账本 `ledger.jsonl` 出现 `type:"reply-scan"`；活动页可筛「接话」「接话扫描」。
4. 若某轮完全没写扫描：概览「接话」卡标红「未扫描」，`duty.log` 有 `本轮未做接话扫描（不合规）`。
5. 设置 → 三个子页签：行式布局，改完出现保存条，保存后概览 limits/下一轮立即变。
